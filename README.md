# 🩸 About the Project

**Deadpool Comic Chaos Hub** is an interactive Deadpool-themed web
experience designed around a comic-book visual style and playful user
interactions.

The experience contains:

-   🏢 Mercenary HQ
-   😂 Meme Vault
-   💥 Chaos Room
-   🕵️ Missions
-   ⚔️ Armory
-   🔐 Secret Area
-   ☎️ Deadpool Hotline
-   🥷 Hidden collectibles
-   🎭 Fourth-wall interactions

The application combines animated UI, client-side state management,
browser-generated sound effects, multilingual content, simulated
authentication, missions, collectibles, and hidden interactions.

# ✨ Feature Showcase

## 🏠 Interactive Hero

-   Start Adventure interaction
-   Chaos Room shortcut
-   Deadpool Hotline
-   Random chaos events
-   Hidden Chimichanga
-   Decoy buttons
-   Fourth-wall humor

## 🏢 Mercenary HQ

-   Interactive corkboard notes
-   Red Merc Hotline
-   Lockers
-   Hidden Chimichangas
-   Cassette / radio interaction

## 😂 Meme Vault

-   Meme cards
-   Flip interactions
-   Punchline reveals
-   Like / laugh / cringe reactions
-   Random chaos meme generation
-   Client-side interaction state

## 💥 Chaos Room

The Chaos Room acts as an interactive playground where users can trigger
events, accumulate Chaos Points, experience visual effects such as
screen shaking, and progress toward the Secret Area.

## 🕵️ Investigation Mission

### The Missing Chimichanga

Players can:

1.  Inspect clues
2.  Explore investigation paths
3.  Interact with characters/events
4.  Progress through mission stages
5.  Solve the case
6.  Unlock the Master Detective badge
7.  Replay the investigation

## ⚔️ Armory

  Equipment                      Interaction
  ------------------------------ ----------------------------------------
  ⚔️ Twin Katanas                Equipment selection + test interaction
  🐔 Tactical Rubber Chicken     Interactive equipment
  🦄 Emotional Support Unicorn   Interactive equipment
  🌯 Chimichanga Launcher 3000   Interactive equipment
  💣 C-4                         Comedic themed interaction

## 🔐 Secret Area

-   Unlock mechanics
-   Cheat-code interaction
-   Alternate suit themes
-   Taco rain
-   Hidden interactions

## 🥷 Hidden Collectibles

Chimichangas are hidden throughout the experience and form part of the
exploration system.

## ☎️ Deadpool Hotline

Interact with the fictional hotline to receive randomized responses.

## 🔊 Synthesized Sound Effects

Sound effects are generated directly in the browser using the Web Audio
API instead of relying on external MP3 files.

## 🌍 Multilingual Interface

🇬🇧 English · 🇮🇳 Hindi · 🇮🇳 Marathi

## 🔐 Simulated Authentication

Login/signup interfaces with client-side validation are included.
Authentication is currently simulated and does not connect to a real
authentication backend.

## 🎭 Deadpool Avatar

A floating Deadpool avatar provides changing dialogue, expressions and
sound effects.

## 👁️ Eye Follower

A cursor-following interaction adds personality to the interface and is
adapted for touch devices.

## 🥚 Easter Eggs

-   Logo interactions
-   Keyboard shortcuts
-   Hidden Chimichangas
-   Secret Area
-   Party Mode

# 🧠 Architecture

``` text
                    ┌─────────────────────┐
                    │      main.tsx       │
                    │   React Entry Point │
                    └──────────┬──────────┘
                               │
                               ▼
                    ┌─────────────────────┐
                    │       App.tsx       │
                    │  Central App State  │
                    └──────────┬──────────┘
                               │
          ┌────────────────────┼────────────────────┐
          │                    │                    │
          ▼                    ▼                    ▼
   ┌─────────────┐      ┌─────────────┐      ┌─────────────┐
   │   Sections  │      │ Interactive │      │    Utils    │
   │ Components  │      │ Components  │      │             │
   └─────────────┘      └─────────────┘      └─────────────┘
          │                    │                    │
          ▼                    ▼                    ▼
      HQ / Meme             Avatar /              Audio /
      Missions /             Hotline /           Translations
      Armory /               Chaos /
      Secret Area             Auth
```

### Central State

`App.tsx` coordinates:

-   Current section
-   Language
-   User state
-   Mission progress
-   Chaos Points
-   Secret Area status
-   Collectibles
-   Theme
-   Notifications

# 🚀 Getting Started

## Prerequisites

-   Node.js
-   npm
-   Git
-   Modern web browser

## 1️⃣ Clone the Repository

``` bash
git clone https://github.com/rohittenv-dev/deadpool.chaoss.git
cd deadpool.chaoss
```

## 2️⃣ Install Dependencies

``` bash
npm install
```

## 3️⃣ Start Development Server

``` bash
npm run dev
```

Open:

``` text
http://localhost:3000
```

# ⚠️ Current Limitations

-   Authentication is simulated client-side.
-   There is currently no database or backend server.
-   Application state is primarily client-side.
-   No persistent server-side accounts are implemented.
-   Sound effects depend on browser Web Audio API support.
